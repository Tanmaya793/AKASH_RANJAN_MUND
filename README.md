# Akash Ranjan Mund - Landing Page Portfolio

Official portfolio site for Para-Badminton World Champion, Akash Ranjan Mund.

## Project Structure
- `index.html` - Semantic layout, structural sections, and content.
- `styles.css` - Custom Kinpaku design language styles, gradient headings, and responsive elements.
- `script.js` - Interactive tab panel logic, scroll-animations, and custom cursor-flashlight follower.
- `assets/` - High-quality cinematic image assets.

## Preview Locally
To run locally, you can start a local static server:
```bash
python -m http.server 8000
```
Then visit: http://localhost:8000
